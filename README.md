# HR Analytics Dashboard using Microsoft Excel

## 📌 Project Overview
This project is an interactive HR Analytics Dashboard built using Microsoft Excel.

The dashboard helps analyze:
- Employee distribution by department
- Gender distribution
- Age group analysis
- Salary range analysis

## 🚀 Features
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Interactive Dashboard
- Data Visualization

## 📊 Key Insights
- Research & Development has the highest workforce
- Employees aged 26–35 dominate the workforce
- Lower salary ranges contain more employees
- Male employees are higher than female employees

## 🛠 Tools Used
- Microsoft Excel
